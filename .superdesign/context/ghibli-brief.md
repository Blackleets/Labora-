# Ghibli brief for Labora+ Login design

Product: Labora+ — Spanish fiscal/workspace app for delivery riders (repartidores) and gestores.
Audience: Spain, Spanish UI copy only.

Visual direction (MUST):
- Warm Studio-Ghibli–inspired meadow landscape (soft hills, grass, clouds, sun glow, dirt path) — MORE illustration/prado, scenic left panel dominating desktop
- Cream parchment auth card (right): `#FFFEFB` / `#FAF6EE`, border `#E8DFC8`, radius ~28px
- Forest green `#2F5D4A`, clay CTA `#C96846`→`#D97757`, gold accents `#B87A24`
- Canvas `#F7F3EA` — NEVER dark SaaS / zinc / slate / cyber neon
- Serif display titles, soft shadows `rgba(47,93,74,0.10)`
- Mobile: meadow strip on top of card
- Logo: forest mark + Labora+ wordmark
- Copy examples: "Entrar", "Crear cuenta", "Correo", "Contraseña", atmosphere titles like "Amanecer en la Colina"

Device: mobile-first phone + desktop split (meadow | card).
